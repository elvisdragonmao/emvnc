First release of emvnc, a native VNC viewer for macOS built with SwiftUI and AppKit.

## Highlights

- **Saved connections** with thumbnails of the last remote screen, favorites, recents, search, grid and list views,
  and Quick Connect for one-off sessions. Hostnames, IPv4 and IPv6 addresses.
- **Authentication:** VNC Password, Apple Remote Desktop, UltraVNC MS-Logon II, no authentication, and
  **RSA-AES / RSA-AES-256**, which encrypts the whole session. The server's key is remembered on first use.
  Passwords are stored only in the macOS Keychain.
- **Keyboard** with real key presses and releases, mapping profiles for Mac and Windows/Linux servers, shortcut
  pass-through and a Send Keys menu (Ctrl-Alt-Delete, Windows key, Alt-Tab, …).
- **Clipboard:** two-way Unicode text, scoped to the session window you are using.
- Fit-to-window and actual-size scaling, full screen, automatic reconnect, screenshot history.

## Install

1. Download `emvnc-1.0.0.zip`, unzip it and move `emvnc.app` to Applications.
2. This build is signed ad hoc and not notarized, so macOS blocks the first launch. Open the app once, then choose
   *System Settings ▸ Privacy & Security ▸ Open Anyway*.

Requires macOS 14 Sonoma or later. The app is universal and runs natively on Apple silicon and Intel Macs.

To check the download: `shasum -a 256 -c emvnc-1.0.0.zip.sha256`

## Tested with

- TigerVNC (VNC Password, Extended Clipboard)
- A server offering RSA-AES-256

Apple Remote Desktop / macOS Screen Sharing and UltraVNC MS-Logon II have not been tested against real servers yet.
Reports are welcome.

## Known limitations

- VeNCrypt (TLS) is not supported. Enable RSA-AES, VNC Password or Apple Remote Desktop on the server.
- The clipboard carries text only. No file transfer, audio or view-only mode.
- VNC Password, Apple Remote Desktop and MS-Logon II do not encrypt the screen or keystrokes. Use RSA-AES, a VPN or
  an SSH tunnel on untrusted networks.
